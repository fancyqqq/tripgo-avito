ANALYZE trips was executed before measuring. No scan types were disabled.
Threshold parameter: 60 seconds.

Both executions use Bitmap Index Scan on trips_active_last_position_idx,
then Bitmap Heap Scan and Sort. Neither plan uses Seq Scan.
Execution times describe this local, cached dataset only.

SELECT id, driver_id, COALESCE(last_position_at, started_at) AS last_activity_at
FROM trips
WHERE status = 'active'
  AND COALESCE(last_position_at, started_at) < now() - ($1::double precision * interval '1 second')
ORDER BY COALESCE(last_position_at, started_at) ASC, id ASC;
